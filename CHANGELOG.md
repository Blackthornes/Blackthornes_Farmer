# Changelog

Versions follow [semantic versioning](https://semver.org): the middle number
moves for new behaviour, the last for fixes alone.

## 0.1.0

First public release, for WoW: Forever (interface 16001).

- Search any material and see every mob, node or vendor it comes from, with
  zone, level range and drop rate, lowest level first.
- Search by zone, mob or category to see what is worth farming there.
- 205 items across 652 sources. Each source is marked as Classic data until
  it has been confirmed on Forever; 77 are confirmed so far.
- Kills and loot panel that tallies what you farm and turns it into drop rates
  once a mob has 20 kills.
